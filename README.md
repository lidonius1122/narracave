# Narracave

**Narracave** ist eine App für deinen eigenen [Audiobookshelf](https://www.audiobookshelf.org)-Server –
auf iPhone, iPad, Apple Watch und im Auto mit CarPlay. Hörstand auf allen Geräten, Offline-Downloads,
Kapitel, Schlaf-Timer und mehrere Designs. Ohne eigenen Server kannst du in der App eine Demo mit
Beispielbüchern ausprobieren.

Narracave ist eine unabhängige App und nicht mit dem Audiobookshelf-Projekt verbunden. Der Quellcode
der App ist nicht öffentlich; dieses Repository enthält nur Support und rechtliche Angaben.
